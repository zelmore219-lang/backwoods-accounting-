# Categorized recipe documents

Production Windows 1.0.2 retains the existing daily production, packaging and release screens. In **Manager tools → Recipes**, choose **Import recipe documents** and select the original ODT recipe files from the owner PC. Documents named for peanuts, coffee, ice cream or pickles are grouped into those categories. Review the preview, then choose **Import drafts**.

Files are read locally and saved into the existing Production database. The public installer contains the importer, not the owner's recipe documents. Recipe import is available before the company connection is configured, using the existing local manager; after connection, the existing Employee manager authorization applies.

The category selector filters recipes and their full source documents. Repeated named formulas keep their alternate source text rather than doubling ingredient quantities. The original documents, production methods, roast profiles, flavoring notes, SOPs and other reference information remain readable under **Source documents & process notes**. Importing the same documents again retains existing entries. It does not overwrite an approved formula or add stock, assets, purchases, financial balances or sale-ready inventory.

Imported formulas start as **Draft · review required**. Confirm quantities/ranges, base formulas and substitutions, map actual ingredients, and enter the standard batch weight and measured finished yield in pounds. Volume units remain in the source until a confirmed weight is supplied; the importer does not guess densities or overrun. Where exact mass quantities exist, zero-stock material references and draft BOM lines are prepared. Set actual purchase costs and receive real lots through the existing supply workflow. Review the original formulation and save the draft before approving a version. Original source versions remain available after editing.

Missing equipment specifications are not fabricated from a document title. Reference descriptions do not create owned equipment or accounting assets. Finished-product stock still transfers to Vendor only after actual production, packaging, inspection and release.
